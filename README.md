# JessTech Edu Studio

Générateur de cahiers d'activités imprimables pour enfants, mis en scène par Filou le renard.

## Prérequis
Node.js 20.19+ ou 22.12+ (exigé par Vite 8).

## Lancer le projet
```bash
npm install
npm run dev     # serveur de développement
npm run build   # build de production (vérifie aussi les types)
npm run lint    # analyse du code (oxlint)
```
