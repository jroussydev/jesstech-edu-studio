# Documentation · JessTech Edu Studio

La documentation est rangée en trois familles :
- **le projet** (fichiers numérotés) : *quoi* construire, dans l'ordre de la Méthode JessTech ;
- **`journal/`** : *ce qui s'est passé*, daté ;
- **`methode/`** : *comment* je travaille, valable pour tous mes projets.

## Le projet
| Fichier | Contenu |
|---|---|
| `00-vision.md` | Pourquoi le projet existe, pour qui, ce que fait la V1 |
| `01-cahier-des-charges.md` | Exigences (F1 à F22), structure du cahier, planning, évolutions |
| `02-analyse-des-besoins.md` | Profils, adaptations, vocabulaire, trame d'Halloween, costumes de Filou |
| `03-analyse-fonctionnelle.md` | Parcours, écrans, ordre des pages, règles de gestion RG1 à RG13 |
| `04-architecture.md` | Décisions techniques, arborescence, modèle de données, flux |
| `05-maquettes.md` | Maquettes et références visuelles |
| `06-catalogue-jeux.md` | Les 97 jeux : catégories, difficultés, supports, variantes ; règles RG14 à RG20 |
| `07-feuille-de-route.md` | Parcours cible V2, idées, étapes V1 à V3 |
